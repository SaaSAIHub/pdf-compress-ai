# Contributing

This repository contains the official product documentation for PDF-Compress.ai. Product feedback is collected in our [FeedLog portal](https://pdf-compress-ai.feedlog.ai/). The website's application source code is not included here.

## Report a problem

Search existing feedback in [FeedLog](https://pdf-compress-ai.feedlog.ai/) before submitting a new request in the **Bug Report** board. Describe what you expected, what happened, and how to reproduce it. Include the browser, operating system, compression mode, approximate file size, and page count when available.

Do not include confidential PDFs, personal documents, credentials, or unreviewed network logs in feedback posts or attachments. Prefer a synthetic sample that you have permission to share.

## Suggest an improvement

Use the **Feature Requests** board in [FeedLog](https://pdf-compress-ai.feedlog.ai/). Explain the task you are trying to complete and what makes the current workflow difficult. A concrete use case helps more than a feature name alone.

## Improve the documentation

Pull requests for corrections, clearer instructions, and reproducible troubleshooting notes are welcome. Keep product claims consistent with the current website and distinguish an observed result from a general guarantee.

Before submitting a documentation change:

- Preview the Markdown and check relative links and images.
- Verify any product behavior that changed.
- Include test conditions when adding measurements.
- Remove private information from examples and screenshots.

For privacy questions, use the contact method in the website's [Privacy Policy](https://pdf-compress.ai/privacy-policy).
