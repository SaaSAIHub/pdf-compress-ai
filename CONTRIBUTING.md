# Contributing

This repository contains the official product documentation and feedback forms for PDF-Compress.ai. The website's application source code is not included here.

## Report a problem

Search existing issues before opening a [bug report](https://github.com/SaaSAIHub/pdf-compress-ai/issues/new?template=bug_report.yml). Describe what you expected, what happened, and how to reproduce it. Include the browser, operating system, compression mode, approximate file size, and page count when available.

Issues are public. Do not attach confidential PDFs, personal documents, credentials, or unreviewed network logs. Prefer a synthetic sample that you have permission to share.

## Suggest an improvement

Use the [feature request form](https://github.com/SaaSAIHub/pdf-compress-ai/issues/new?template=feature_request.yml). Explain the task you are trying to complete and what makes the current workflow difficult. A concrete use case helps more than a feature name alone.

## Improve the documentation

Pull requests for corrections, clearer instructions, and reproducible troubleshooting notes are welcome. Keep product claims consistent with the current website and distinguish an observed result from a general guarantee.

Before submitting a documentation change:

- Preview the Markdown and check relative links and images.
- Verify any product behavior that changed.
- Include test conditions when adding measurements.
- Remove private information from examples and screenshots.

For privacy questions, use the contact method in the website's [Privacy Policy](https://pdf-compress.ai/privacy-policy).
